## Sistema Johnny Decimal no UpNote

**Estrutura observada:**
- **Áreas:** 00-90 (dezenas)
- **Categorias:** 10-19, 20-29, etc. (dezenas dentro de áreas)
- **Subcategorias:** 12.01, 12.02, etc. (decimais)

**Exemplo real:**
```
10 - Vida Pessoal
  └─ 12 - Saúde
      └─ 12.01 - Idas ao médico
```

**Características:**
- Prefixos numéricos facilitam ordenação
- Hierarquia clara de 3 níveis (Área > Categoria > Item)
- Sistema escalável e organizado
- Navegação intuitiva por números

```yaml
date: YYYY-MM-DD HH:mm:ss
created: YYYY-MM-DD HH:mm:ss
categories:
- Caderno / Subcategoria / Item
---
```

**Pontos fortes:**
- Sistema Johnny Decimal bem estruturado
- Interface visual organizada
- Captura rápida consistente (~103 notas/mês por 23 meses)
- Suporte a anexos e mídias
- Hierarquia clara de categorias
- Uso diário sustentado por quase 2 anos

**Desafios:**
- 53% das notas aguardando categorização
- Volume grande de backlog (1248 notas)
- Necessidade de processamento manual

## Uso Real do UpNote

**Contexto:** Substituiu Evernote na captura móvel (dez/2023)

**Casos de uso principais:**

1. **Finanças (foco primário)**
   - Captura de comprovantes (fotos)
   - Balanço financeiro
   - Registros de transações

2. **Conhecimento**
   - Clippings web
   - Interesses e referências

3. **Saúde**
   - Exames médicos (anexos PDF)
   - Prontuários médicos
   - Registros de consultas

4. **Treino**
   - Notas de treino para progressão segura
   - Acompanhamento físico

5. **Tentativas não consolidadas**
   - Dieta (tentativas)
   - Diário (tentativas)

**Padrão identificado:**
- **Funciona:** Captura de documentos (comprovantes, exames)
- **Funciona:** Clippings e referências
- **Não consolidou:** Hábitos contínuos (diário, dieta)

## Contexto: UpNote vs Raccoon

Sistemas complementares com propósitos distintos:

**UpNote (desde dez/2023):**
- Substituiu Evernote na captura móvel
- Foco: comprovantes, exames, clippings
- Sistema Johnny Decimal consolidado
- 2358 notas acumuladas (103/mês)
- Estrutura hierárquica 00-90
- **Forte em:** Captura de documentos
- **Fraco em:** Hábitos contínuos (diário, dieta)

**Raccoon (desde nov/2025):**
- Laboratório de processamento local
- IA assistida (Claude Code)
- Sistema de finanças ATIVO (funciona!)
- Timeline de diário (nascente, mas consistente)
- Estrutura flat com pastas 00-90
- **Complementa UpNote:** Processa o que UpNote captura

**Estratégia atual:**
- UpNote continua capturando (comprovantes, exames, clippings)
- Raccoon processa backlog (1248 sem categoria)
- Raccoon testa workflows que não funcionaram no UpNote (diário consolidou aqui)
